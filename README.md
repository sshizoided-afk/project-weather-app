Погода

Веб‑приложение “Погода” на чистом JavaScript, которое позволяет ввести город и получить текущие погодные условия, а также блок с прогнозом. Интерфейс включает карточку с результатом и сообщения об ошибках при некорректном запросе.

Стек
- Frontend: HTML, CSS, JavaScript (ES Modules / `type="module"`)
- Backend: нет
- DB: нет

Как запустить локально
1. Склонируйте репозиторий: https://github.com/sshizoided-afk/project-weather-app.git
2. Перейдите в папку проекта: cd project-weather-app
3. Поднимите локальный сервер (нужен из‑за type="module") npx serve.
4. Откройте в браузере URL, который покажет команда.

Ссылка на деплой: https://sshizoided-afk.github.io/project-weather-app/
